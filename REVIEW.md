## Looked at and decided it was not a defect, and why
- `load_dotenv()` (line 20): by default it does not override real environment variables. So `MONGO_URI` and `MONGO_DB` set by the grader win over my local `.env`. That is what the assignment asks for.
- Plain `def` endpoints, not `async def`: FastAPI runs plain `def` functions in a thread pool, and PyMongo is thread-safe, so parallel requests work. Using `async def` with the normal PyMongo driver would block the server, so I kept `def`.
- `doc.pop("_id", None)` after `insert_one` (lines 84 and 120): `insert_one` adds `_id` to the dict, so removing it before returning is correct. The real problems in those functions are elsewhere. My version builds the response field by field, so I do not depend on it.
- The default `mongodb://localhost:27017` and `attendance_db` (lines 22 and 23): they are only used when the environment variable is missing. Real values still win, so nothing is hard-coded in practice. I kept them for local use.
